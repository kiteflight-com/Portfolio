# Personal Portfolio Website

A responsive personal portfolio website for Kishalaya Chattopadhyay showcasing skills, experience, education, and projects.

## 🌟 Features

- **Responsive Design**: Fully responsive layout that works on desktop, tablet, and mobile devices
- **Navigation**: Smooth scrolling navigation to different sections
- **About Me**: Personal introduction and professional summary
- **Skills Display**: Visual representation of technical skills with progress bars
- **Experience Timeline**: Interactive timeline showing professional experience
- **Education History**: Timeline showcasing educational background
- **Portfolio Gallery**: Grid layout for showcasing projects with hover effects
- **Contact Form**: Functional contact form for potential employers or clients
- **Social Media Integration**: Links to professional social media profiles

## 🛠️ Technologies Used

- **HTML5**: For structure and content
- **CSS3**: For styling and animations
- - Flexbox for layout
  - CSS animations for interactive elements
  - Media queries for responsiveness
- **Font Awesome**: For icons
- **JavaScript**: For interactive elements (to be implemented)

## 📋 Sections

1. **Header/Banner**: Introduction with name and social links
2. **About**: Short biography and professional summary
3. **Skills**: Technical competencies with visual indicators
4. **Experience**: Professional work history presented in a timeline format
5. **Education**: Academic background displayed chronologically
6. **Portfolio**: Showcase of projects with descriptions
7. **Contact**: Contact form and personal information


## 🔧 Customization

To customize this portfolio for your own use:

1. Replace personal information in `index.html`
2. Update the profile image (place your image in the root directory)
3. Modify the skills section to reflect your own technical skills
4. Update the timeline sections with your own experience and education
5. Add your own projects to the portfolio section
6. Update contact information and social media links

## 📱 Responsive Design

The website is fully responsive and has been tested on various screen sizes:
- Desktop: 1200px and above
- Tablet: 768px to 1199px
- Mobile: Below 768px
